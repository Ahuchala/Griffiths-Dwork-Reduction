# Griffiths-Dwork Reduction

Macaulay2 / Sage / GAP scripts accompanying the PhD thesis on
pole-order reduction (Griffiths-Dwork method) for hypersurfaces in
Grassmannians. The thesis lives at `pole-order-reduction/thesis`; this
repo holds the computational backing for the examples and tables.

The central computation is: given a smooth hypersurface
Z = V(f) ⊂ Gr(k, n) of degree d, construct the Jacobian-style ideal
J_f generated by f and the E_{ij}(f) (the gl_n action on Plucker
coordinates), and compute the graded pieces (R / J_f)_{pd - n}. These
match the primitive Hodge numbers h^{N-p, p-1}_prim(Z), which are
independently computable in Schubert2.

## Dependencies

- **Macaulay2** ≥ 1.24 with packages `Resultants`, `TensorComplexes`,
  `WeilDivisors`, `Schubert2`, `Cyclotomic`.
- **SageMath** ≥ 10.0.
- **GAP** ≥ 4.13.

## Notes

- `NonExamples.M2` samples one random f per (k, n, d) without verifying
  smoothness. If a row disagrees with the primitive Hodge numbers,
  re-run -- a singular draw produces incorrect results. Three cases are
  flagged SLOW in source: (3, 6, 2), (2, 5, 3), (2, 6, 3).
- Coefficient fields vary by file: `QQ` (exact) vs `ZZ/p` (much faster
  Gröbner bases). The thesis examples are chosen so the finite-field
  computation reflects the rational answer.
- `hodge.m2` and `hodge.test.m2` are self-contained -- no external M2
  packages required.
